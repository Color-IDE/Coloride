# LOT-001 — Socle Monorepo Cargo/pnpm, Shell Tauri v2 & CI 3 OS

**Domaine :** Fondations & Outillage
**Module :** Racine workspace, `apps/desktop-tauri`, `apps/web-ui`, `.github/workflows/ci.yml`
**Jalon :** `M1.1 - Core & Cockpit Shell`
**Priorité :** P0
**Complexité :** Faible
**Estimation :** 2 jours (16 h)
**Dépendances :** Aucune
**Parallélisable avec :** Aucun (lot fondateur racine)

---

### 4.1 Objectif
Établir la structure cible du monorepo (`Cargo Workspace` + `pnpm workspaces`) avec les 4 crates Rust et les 4 packages/apps TypeScript, fonctionnelle et compilable sur macOS (Apple Silicon), Windows 11 x64 et Ubuntu 24.04 x64 via GitHub Actions.

### 4.2 Périmètre
- **IN :**
  - Configuration `Cargo.toml` workspace (`crates/host-core`, `crates/context-engine`, `crates/judge-orchestrator`, `crates/sandbox-runner`, `apps/desktop-tauri/src-tauri`).
  - Configuration `pnpm-workspace.yaml` (`apps/desktop-tauri`, `apps/web-ui`, `packages/editor-cm6`, `packages/protocol-types`).
  - Configuration unifiée **Biome** (`biome.json`) et `tsconfig.base.json` en mode strict.
  - Shell minimal Tauri v2 ouvrant une fenêtre native sécurisée (CSP stricte).
  - Alignement et validation du pipeline [`.github/workflows/ci.yml`](../../../.github/workflows/ci.yml) sur les 3 OS.
- **OUT :**
  - Logique métier d'édition, flux IPC binaires, indexation SQLite, agents et sandboxes.

### 4.3 Prérequis
- Chaîne d'outils Rust stable (`rustup`), Node.js LTS + `pnpm`, dépendances système Tauri v2 (`libwebkit2gtk-4.1-dev` sur Ubuntu 24.04, WebView2 sur Windows 11, Xcode CLT sur macOS).

### 4.4 Implémentation
1. Créer le `Cargo.toml` racine déclarant les membres du workspace et les `[workspace.dependencies]` partagées (`tokio`, `serde`, `serde_json`, `thiserror`, `tracing`, `blake3`).
2. Créer `pnpm-workspace.yaml`, `package.json` racine (scripts `lint`, `format`, `typecheck`, `test`, `build`) et `biome.json`.
3. Initialiser les 4 crates Rust (`crates/host-core`, `crates/context-engine`, `crates/judge-orchestrator`, `crates/sandbox-runner`) avec un `src/lib.rs` exposant une fonction `healthcheck()` et un test unitaire.
4. Initialiser `packages/protocol-types`, `packages/editor-cm6`, `apps/web-ui` (React + Vite + TypeScript strict) et `apps/desktop-tauri` (Tauri v2 avec capacités IPC minimales).
5. Vérifier la correspondance exacte des commandes appelées par [`.github/workflows/ci.yml`](../../../.github/workflows/ci.yml).

### 4.5 Tests obligatoires
- **Tests unitaires de santé workspace (Bloquants) :**
  - *Scénario :* Exécution des tests unitaires initiaux des 4 crates Rust et des packages TS.
  - *Préconditions :* Dépendances Cargo et pnpm installées.
  - *Données d'entrée :* `cargo test --workspace` et `pnpm -r test`.
  - *Résultat attendu :* 100 % des tests passent avec code de sortie `0`.
  - *Méthode de vérification :* Exécution CLI locale et CI.
- **Test d'intégration CI Multi-OS (Bloquant) :**
  - *Scénario :* Compilation complète, lint Biome, typecheck TypeScript et Clippy Rust sur macOS, Windows 11 et Ubuntu 24.04.
  - *Préconditions :* Commit poussé sur une branche de travail.
  - *Données d'entrée :* `pnpm biome check .`, `pnpm -r typecheck`, `cargo clippy --workspace --all-targets -- -D warnings`.
  - *Résultat attendu :* `0` erreur et `0` avertissement sur les 3 systèmes d'exploitation.
  - *Méthode de vérification :* Pipeline GitHub Actions `ci.yml`.

### 4.6 Critères d'acceptation
- [x] L'arborescence du monorepo correspond exactement à la structure cible de la section 4 de [ARCHITECTURE_TECHNIQUE.md](../ARCHITECTURE_TECHNIQUE.md).
- [x] `cargo clippy --workspace --all-targets -- -D warnings` et `pnpm -r typecheck` retournent `0` erreur.
- [x] L'application `desktop-tauri` démarre localement et affiche la fenêtre native sans erreur console.

### 4.7 Definition of Done
- Code implémenté et formaté avec Biome / `rustfmt`.
- Critères d'acceptation et tests obligatoires validés sur les 3 OS.
- Contrats d'arborescence respectés, aucune régression introduite.

### 4.8 Risques et rollback
- **Risques :** Divergence de noms de paquets système WebKitGTK sur Ubuntu 24.04.
- **Stratégie de rollback :** Réversion atomique du commit d'initialisation si le cache ou la matrice CI multi-OS est cassée.
