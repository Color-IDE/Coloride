# LOT-019 — Advanced CM6 Extensions (Multi-cursor, Folding, Large Files)

> 🇫🇷 [Version française](../fr/LOTS/LOT-019.md)

**Domain:** CM6 Editor View (Phase 2 — Closed Beta)
**Module:** `packages/editor-cm6`, `crates/host-core`
**Milestone:** `M2.0 - Closed Beta (8-Chat Grid)`
**Priority:** P1 | **Complexity:** Low | **Estimate:** 3 days (24 h)
**Dependencies:** [LOT-004](./LOT-004.md), [LOT-018](./LOT-018.md)

---

### 4.1 Objective
Enhance the CodeMirror 6 editor and `crates/host-core` with Closed Beta editing capabilities: full multi-cursor support, parameterized snippets, syntactic code folding, visual word wrap, advanced regex search/replace, and automatic degraded mode for ultra-large files.

### 4.2 Scope
- **IN:** Multi-selection transactions synchronized atomically with `ropey`, snippet engine, AST/Lezer code folding, word wrap, regex/case-sensitive search & replace, and `LargeFileMode` guard (candidate threshold: `> 5 MB` or `> 50,000 lines`) disabling heavy decorations and full LSP sync in favor of fast chunk streaming.
- **OUT:** Real-time Yjs co-editing ([LOT-023](./LOT-023.md)).

### 4.3 Prerequisites
- [LOT-004](./LOT-004.md) and [LOT-018](./LOT-018.md).

### 4.4 Implementation
1. Extend `host-core` transaction application to apply `N` ordered multi-cursor replacements atomically in a single revision while incrementally updating `Tree-sitter`.
2. Implement `LargeFileMode` pre-check in `host-core` and `editor-cm6` with an explicit status banner.

### 4.5 Mandatory Tests
- **Multi-Cursor & Batch Regex Replace Property Test (`proptest`, Blocking):** 100 transactions with 2 to 100 concurrent cursors on a 5,000-line file converge 100% between `EditorState` and `ropey::Rope` in `< 16 ms`.
- **Ultra-Large File Open Performance Test (Blocking):** Open a 20 MB (250,000-line) file in `< 300 ms` in explicit degraded mode with zero UI freeze.

### 4.6 Acceptance Criteria
- [ ] Multi-cursor, snippets, folding, word wrap, and regex search/replace validated on all 3 OSes.
- [ ] Smooth opening of files exceeding the size threshold in degraded mode.

### 4.7 Definition of Done
Advanced CM6 Beta extensions delivered and verified.

### 4.8 Risks & Rollback
- **Risk:** Catastrophic regex backtracking (*ReDoS*) in user search queries.
- **Mitigation:** Execute regex searches in Rust using the linear-time $O(N)$ `regex` crate.
