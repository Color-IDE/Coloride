# LOT-012 — 0-VM Native OS Sandbox (Seatbelt, Landlock, AppContainer) & Warm OCI

> 🇫🇷 [Version française](../fr/LOTS/LOT-012.md)

**Domain:** Execution Isolation & Security
**Module:** `crates/sandbox-runner`
**Milestone:** `M1.3 - The Judge & OS Sandbox`
**Priority:** P0 | **Complexity:** High | **Estimate:** 5 days (40 h)
**Dependencies:** [LOT-011](./LOT-011.md)

---

### 4.1 Objective
Implement in `crates/sandbox-runner` local isolated execution without requiring Docker: **Tier 1 by default (0-VM OS-native kernel sandbox in < 5 ms)** on macOS (`sandbox-exec`/Seatbelt), Linux (`Landlock` + `bubblewrap`/namespaces), and Windows (`AppContainer` + `Job Objects`), plus **Tier 2 optional (`WarmSandboxPool` OCI)** supporting OrbStack, Docker Desktop, and Podman, under a strict **Fail-Closed** policy (zero silent fallback to the host shell).

### 4.2 Scope
- **IN:** Unified `SandboxRunner` trait; CPU, memory, disk, process count, duration, and log volume quotas; canonical path resolution and symlink/directory traversal guards; macOS Seatbelt profile, Linux Landlock+bubblewrap profile, Windows AppContainer+Job Object profile restricting writes to the task `worktree`, blocking `~/.ssh`, `~/.aws`, `~/.gnupg`, OS keyrings, container sockets, and outbound network by default; optional OCI Warm Pool detector (OrbStack/Docker/Podman); and strict **Fail-Closed** enforcement.
- **OUT:** Cloud ECS Fargate runner ([LOT-017](./LOT-017.md)) and Firecracker ([LOT-026](./LOT-026.md)).

### 4.3 Prerequisites
- [LOT-011](./LOT-011.md).

### 4.4 Implementation
1. Implement `PathGuard::verify_within_worktree` resolving symlinks and rejecting any path escaping `worktree_root`.
2. Implement the 3 native OS sandbox drivers behind `OsNativeSandbox` with a startup self-test verifying filesystem and network isolation.
3. Implement process-tree termination (`killpg` / `KILL_ON_JOB_CLOSE`) to guarantee clean teardown on cancellation, timeout, or fork bomb.
4. Implement `OciRuntimeDetector` and unprivileged pre-warmed container pool (`--cap-drop=ALL --security-opt=no-new-privileges --network=none`).

### 4.5 Mandatory Tests
- **Anti-Escape & Intrusion Security Suite (Blocking across macOS, Ubuntu 24.04, Windows 11 — Section 5 Blocking Scenarios):**
  - *Scenario 1 (Symlink & Host Secrets):* Attempt to read `~/.ssh/id_rsa`, `~/.aws/credentials`, write to `../outside`, and follow a symlink `worktree/escape -> /etc/passwd`.
  - *Scenario 2 (Network & Cloud Metadata):* Attempt outbound connections to `https://example.com` and `http://169.254.169.254/latest/meta-data/`.
  - *Scenario 3 (Fork Bomb, RAM, Disk & Log Saturation):* Spawn recursive processes, exceed RAM quota, and flood `stdout` with 500 MB.
  - *Scenario 4 (Fail-Closed):* Simulate sandbox initialization failure and verify `0` commands run on the host shell.
- **Startup Performance Test (Blocking):** OS-native sandbox instantiation overhead **p95 < 5 ms**.

### 4.6 Acceptance Criteria
- [ ] OS-native sandbox starts in **< 5 ms** without Docker or Podman installed.
- [ ] 100% of escape attempts (symlink, path traversal, `~/.ssh`, `~/.aws`, Docker socket, outbound network, cloud metadata) are blocked and audited across all 3 OSes.
- [ ] Bounded termination and cleanup on fork bomb or resource saturation.
- [ ] Zero silent fallback to the host shell.

### 4.7 Definition of Done
`sandbox-runner` crate implemented and qualified across the macOS, Windows, and Ubuntu CI matrix.

### 4.8 Risks & Rollback
- **Risk:** Node/TypeScript build tools requiring writable temp directories.
- **Mitigation:** Mount an isolated per-task `TMPDIR` inside the temporary worktree, automatically purged on task completion.
