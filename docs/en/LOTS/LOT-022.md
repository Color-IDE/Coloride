### 4.1 Objective
Deploy the three industrialization pillars for Closed Beta: native & differential **Prompt Caching** (reducing inference cost and latency on stable `ContextBundle` prefixes with strict tenant isolation), versioned & revocable **Team/Project Memory**, and full **OpenTelemetry** observability redacted of all source code and prompts by default.

### 4.2 Scope
- **IN:** Deterministic ordering of `ContextBundle` prefixes with native `cache_control` markers partitioned by `(tenant_id, workspace_id, model_id, policy_hash)` (zero cross-tenant cache sharing); governed project memory (`.coloride/conventions.md` where agent-proposed conventions require explicit human approval before activation and support 1-click revocation); and OpenTelemetry correlation (`task_id` ↔ `run_id` ↔ `snapshot_id` ↔ `model_call_id`) with zero source code or prompts exported by default.
- **OUT:** Multi-org SAML/SCIM Enterprise audit ([LOT-027](./LOT-027.md)).

### 4.3 Prerequisites
- [LOT-009](./LOT-009.md), [LOT-014](./LOT-014.md), [LOT-018](./LOT-018.md).

### 4.4 Implementation
1. Implement `PrefixCacheOptimizer` stabilizing the static prefix (system instructions + team memory + repo graph) and appending only differential deltas on subsequent turns.
2. Implement `ProjectMemoryManager` enforcing the `Proposed → Approved (vN) → Revoked` lifecycle.
3. Implement `ZeroCodeByDefaultProcessor` stripping any non-whitelisted payload attribute from OpenTelemetry spans unless diagnostic opt-in is enabled and secret-redacted.

### 4.5 Mandatory Tests
- **Cross-Tenant Cache Isolation & Prompt Caching Hit Rate Test (Blocking):** Run 5 consecutive turns on a workspace (Tenant A) and verify **≥ 70%** prefix cache hit rate from turn 2 onward; verify `0` cache reuse by Tenant B.
- **Team Memory Governance & Telemetry Redaction Test (Blocking):** Verify an unapproved agent convention is never injected into subsequent tasks, and inspect all exported OpenTelemetry spans to confirm `0` bytes of source code, prompts, or secrets.

### 4.6 Acceptance Criteria
- [ ] Native *Prompt Caching* active with strict tenant and policy isolation.
- [ ] Model outputs never automatically become active project memory rules without human approval.
- [ ] OpenTelemetry spans correlate `task_id`, `run_id`, and `snapshot_id` with zero code/prompt leakage by default.

### 4.7 Definition of Done
Prompt Caching, governed team memory, and OpenTelemetry delivered and validated. **Milestone `M2.0 - Closed Beta` ready.**

### 4.8 Risks & Rollback
- **Risk:** Dynamic timestamps placed at the top of the prompt invalidating prefix caches.
- **Mitigation:** Strictly separate the immutable prefix from dynamic turn suffixes.
