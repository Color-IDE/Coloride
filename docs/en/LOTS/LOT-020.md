**Milestone:** `M2.0 - Closed Beta (8-Chat Grid)`
**Priority:** P0 | **Complexity:** High | **Estimate:** 4.5 days (36 h)

---

### 4.1 Objective
Enable parallel multi-agent orchestration in the Cockpit: running **up to 8 concurrent chats/agents in parallel** (`1 | 2 | 4 | 8`), each isolated in its own *Copy-on-Write* `git worktree`, with **real-time AST conflict detection** across active agents and automatic re-validation upon sequential patch integration.

### 4.2 Scope
- **IN:** Multi-session scheduler in `crates/judge-orchestrator` managing up to 8 concurrent tasks on distinct CoW `git worktree` instances with an explicit task dependency DAG and global CPU/RAM resource semaphore; real-time `AstCrossAgentConflictDetector` comparing `Tree-sitter` symbols touched by active `ChangeSet` proposals (`🟡 ! AST Conflict with Chat #k`); and ordered integration protocol invalidating (`🟠`) and re-testing any concurrent chat whose impact scope intersects a newly accepted chat.
- **OUT:** Multi-human CRDT co-editing ([LOT-023](./LOT-023.md)).

### 4.3 Prerequisites
- [LOT-011](./LOT-011.md), [LOT-015](./LOT-015.md), [LOT-018](./LOT-018.md).

### 4.4 Implementation
1. Scale `CowWorktreeProvisioner` ([LOT-011](./LOT-011.md)) to manage a pool of 8 active worktrees per workspace with shared read-only package stores and fair sandbox scheduling.
2. Implement `AstSymbolLockTable` tracking `(file_path, ast_symbol_path, read_set, write_set)` across all 8 chats and emitting instant conflict alerts on intersection.
3. Maintain `< 10 ms` inspector switching and `p95 ≤ 16 ms` CodeMirror 6 typing while all 8 chats stream simultaneously.

### 4.5 Mandatory Tests
- **8-Agent Parallel Execution & AST Collision Arbitration Test (Blocking):** Run 8 concurrent tasks (6 disjoint, 2 modifying `UserSession` in `src/auth/session.ts`); verify the 6 disjoint tasks reach `🟢 Validated` independently, `#1` and `#2` flag the AST collision on `UserSession`, and accepting `#1` transitions `#2` to `🟠` and triggers automatic rebase + Judge re-verification before `#2` can be merged.
- **8-Stream UI Performance Test (Blocking):** Stream 8 concurrent AI chats while switching the right inspector (`< 10 ms`) and typing in CodeMirror 6 (`p95 ≤ 16 ms`).

### 4.6 Acceptance Criteria
- [ ] Up to 8 concurrent chats execute in isolated `git worktree` instances with zero cross-corruption.
- [ ] 100% detection of AST symbol collisions across active agents.
- [ ] Automatic invalidation and Judge re-verification of any concurrent chat impacted by another chat's merge.

### 4.7 Definition of Done
8-agent parallel orchestrator, AST conflict detector, and 8-chat grid UI delivered and load-tested.

### 4.8 Risks & Rollback
- **Risk:** Local CPU/RAM saturation if 8 heavy test suites run simultaneously on an 8 GB machine.
- **Mitigation:** Hardware-aware concurrency semaphore throttling concurrent heavy sandbox test runs while keeping all 8 agent sessions responsive.
