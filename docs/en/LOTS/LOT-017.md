# LOT-017 — Managed Cloud API (Axum/Postgres/OIDC), Fargate Runner & R2/Pages Publishing

> 🇫🇷 [Version française](../fr/LOTS/LOT-017.md)

**Domain:** Cloud Services, Managed Execution & Publishing
**Module:** Cloud Service (`Rust/Axum`), `crates/sandbox-runner` (Fargate), `crates/host-core` (`PublishService`)
**Milestone:** `M1.4 - MVP Launch Ready`
**Priority:** P1 | **Complexity:** Medium | **Estimate:** 4.5 days (36 h)
**Dependencies:** [LOT-012](./LOT-012.md), [LOT-014](./LOT-014.md), [LOT-016](./LOT-016.md)

---

### 4.1 Objective
Provide the MVP managed cloud infrastructure: **Rust/Axum** API (REST/OpenAPI, cursor-resumable SSE, terminal WebSockets), **PostgreSQL + KMS** storage, **OIDC + PKCE** identity (required only for managed services), isolated per-task cloud sandbox execution on **AWS ECS Fargate** (EU region), and 1-click static publishing to **Cloudflare R2 + Cloudflare Pages/Workers** with instant digest-verified rollback.

### 4.2 Scope
- **IN:** Typed `Rust/Axum` OpenAPI server, cursor-paginated SSE event streams (`Last-Event-ID`), isolated terminal WebSockets, transactional PostgreSQL metadata, tenant-isolated digest-addressed artifacts on S3/Cloudflare R2 + KMS, OIDC Authorization Code + PKCE (never auto-syncing local repositories), single-tenant EU **AWS ECS Fargate** runner (no privileged mode, no Docker-in-Docker, no LLM secrets or deployment IAM roles exposed to build tasks), and 1-click **Cloudflare R2/Pages** static publishing (`< 50 ms` invalidation, $0 egress) with 1-click rollback by digest.
- **OUT:** SSR, hosted server APIs, and secrets in client bundles (explicitly excluded from MVP publishing).

### 4.3 Prerequisites
- [LOT-012](./LOT-012.md), [LOT-014](./LOT-014.md), [LOT-016](./LOT-016.md).

### 4.4 Implementation
1. Implement the `Axum` backend with tenant isolation middleware, cursor-based SSE reconnection, and KMS encryption.
2. Implement `FargateSandboxRunner` launching an ephemeral single-tenant Fargate task per execution and destroying it immediately upon completion.
3. Implement `StaticPublishService`: verify `🟢 Validated` `Evidence`, scan `dist/` with `AclAndSecretScanner` ([LOT-008](./LOT-008.md)), upload content-addressed artifacts by digest to Cloudflare R2, and atomically update the active deployment pointer on Cloudflare Pages/Workers.

### 4.5 Mandatory Tests
- **Publish & 1-Click Digest Rollback Test (Blocking — Section 5 Blocking Scenario):** Publish `V1` (`digest_1`), publish `V2` (`digest_2`), block a `V3` bundle containing a secret, and roll back in 1 click to `V1` (`digest_1`) in `< 1 s`.
- **Cursor SSE Reconnection & Zero Implicit Sync Test (Blocking):** Disconnect SSE at event `#15`, emit `#16..#20`, reconnect with `cursor = 15`, and verify exact delivery of `#16..#20` and zero automatic upload of unselected local repositories.

### 4.6 Acceptance Criteria
- [ ] Promotion and 1-click rollback of digest-verified artifacts on Cloudflare R2/Pages.
- [ ] Zero LLM secrets or cloud deployment roles accessible inside ECS Fargate build tasks.
- [ ] Architecture supports the **99.5%** MVP monthly availability target.

### 4.7 Definition of Done
Axum Cloud service, ECS Fargate adapter, and Cloudflare R2/Pages publishing pipeline delivered and validated.

### 4.8 Risks & Rollback
- **Risk:** Orphaned Fargate tasks increasing cloud cost.
- **Mitigation:** Hard `stopTimeout` and reconciliation watchdog terminating any task exceeding its `TaskSpec` duration budget.
