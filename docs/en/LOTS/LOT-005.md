# LOT-005 — 4-Zone Cockpit UI Shell, Lazy Boot & Virtualization (`web-ui`)

> 🇫🇷 [Version française](../fr/LOTS/LOT-005.md)

**Domain:** Cockpit UI
**Module:** `apps/web-ui`, `apps/desktop-tauri`
**Milestone:** `M1.1 - Core & Cockpit Shell`
**Priority:** P0 | **Complexity:** Medium | **Estimate:** 3.5 days (28 h)
**Dependencies:** [LOT-004](./LOT-004.md)

---

### 4.1 Objective
Assemble the **4-Zone Multi-Chat Cockpit** interface featuring *Lazy Boot* (p95 ≤ 3 s startup), strict re-render isolation (atomic Zustand/Jotai stores), full DOM virtualization for file trees and chat messages, `16 ms` `requestAnimationFrame` stream batching, and `< 10 ms` right inspector synchronization.

### 4.2 Scope
- **IN:** Zone 1 (`Activity Bar`), Zone 2 (Virtualized Dynamic Sidebar: Chat Sessions & File Tree), Zone 3 (Center Tabbed Multi-Chat Grid `1 | 2 | 4 | 8` with Coloride state borders and 16 ms batched streaming), Zone 4 (Right Contextual Inspector `[ 👁 Preview | 💻 Code & Diff ]` synced in `< 10 ms`), explicit Persona selector (*Create*, *Learn*, *Develop*, *Infrastructure*, *Data*), and *Lazy Boot* session restoration.
- **OUT:** Parallel backend execution of 8 concurrent agents (activated in [LOT-020](./LOT-020.md); MVP executes 1 active task at a time).

### 4.3 Prerequisites
- [LOT-004](./LOT-004.md).

### 4.4 Implementation
1. Partition Zustand/Jotai atoms by zone so streaming chat tokens never trigger re-renders of the file tree or CodeMirror 6 inspector.
2. Implement `FrameBatchedStreamRenderer` coalescing incoming AI tokens and terminal log lines into `16 ms` (`requestAnimationFrame`) ticks.
3. Virtualize the file tree (> 50,000 entries) and chat message list.
4. Implement *Lazy Boot* restoring window layout and the active CodeMirror 6 buffer in `≤ 3 s` before background initialization of heavy services.

### 4.5 Mandatory Tests
- **Typing Stability Under Heavy Streaming Load (Blocking — Section 5 Blocking Scenario):** Stream 150 tokens/s in chat + continuous terminal logs + 30,000-node file tree while typing in CodeMirror 6; verify `0` editor remounts, stable cursor/scroll, and **p95 ≤ 16 ms** keystroke latency.
- **Lazy Boot & Inspector Switch Performance Tests (Blocking):** Cold startup **p95 ≤ 3 s**; right inspector switch **< 10 ms**.

### 4.6 Acceptance Criteria
- [ ] Desktop startup to interactive UI measured at **p95 ≤ 3 s**.
- [ ] Right inspector synchronization with selected chat in **< 10 ms**.
- [ ] `0` CodeMirror 6 remounts during chat streaming or `1 | 2 | 4 | 8` grid switching.

### 4.7 Definition of Done
4-zone Cockpit, virtualization, and *Lazy Boot* delivered and benchmarked.

### 4.8 Risks & Rollback
- **Risk:** Markdown parsing jank on long streaming code blocks.
- **Mitigation:** Incremental block-level Markdown parser caching finalized paragraphs.
