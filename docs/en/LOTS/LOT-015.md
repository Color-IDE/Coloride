### 4.1 Objective
Deliver the complete **Coloride Deterministic Judge** loop: compiling AST-anchored `ChangeSet` operations (`Tree-sitter`) or verified `SEARCH/REPLACE` blocks, running prioritized impacted tests (*Test Impact Analysis* in < 2 s) + `vtsls` + Biome inside the native OS sandbox, enforcing the 2-retry auto-correction loop, assigning `🟢/🟡/🔴/🟠/🔵` states bound to the exact revision hash, and enabling interactive review via `@codemirror/merge`.

### 4.2 Scope
- **IN:** `AstChangeSetCompiler` compiling symbol-anchored AST edits into exact diffs on immutable snapshots; strict `base_revision` verification and conflict detection if the user edited the target during the task; Judge verification pipeline in the native OS sandbox (Biome + `vtsls` + impacted tests in `< 2 s` + full suite) producing signed `Evidence`; auto-correction feedback loop capped at **2 retries**; interactive unified and side-by-side `@codemirror/merge` review (`[✓ Accept]`, `[✕ Reject]`, `[Request Adjustment]`); and debounced background re-verification of `🟠 Stale Validation` ranges.
- **OUT:** Browser runtime verification via `Preview Service` (added to `Evidence` in [LOT-016](./LOT-016.md)).

### 4.3 Prerequisites
- [LOT-004](./LOT-004.md), [LOT-010](./LOT-010.md), [LOT-013](./LOT-013.md), [LOT-014](./LOT-014.md).

### 4.4 Implementation
1. Implement `AstChangeSetCompiler::compile(&Rope, &Tree, &ChangeSet)` resolving target AST nodes, verifying base revision hashes, and computing exact UTF-8/UTF-16 offsets and `result_digest`.
2. Implement `JudgePipeline::evaluate_changeset`: create invisible Git checkpoint, apply patch in the isolated worktree, run `biome check`, `vtsls`, and impacted tests (`vitest related`) in the OS sandbox, and emit `Evidence`.
3. Enforce the 5 Coloride states (`🟢 Validated`, `🟡 Needs Review`, `🔴 Failed`, `🟠 Stale Validation`, `🔵 Unchanged Source`) and wire `@codemirror/merge` into the right inspector.

### 4.5 Mandatory Tests
- **End-to-End Judge Loop & 2-Retry Cap Test (Blocking):** Agent submits a failing patch on attempt 1 (`🔴`), receives structured `Evidence`, fixes it on attempt 2 (`🟢`); verify first impacted-test feedback in **< 2 s** and immediate stop if attempt 2 fails again.
- **Concurrent User Edit Conflict Test (Blocking — Section 5 Blocking Scenarios):** User edits a function while an agent patch is in flight; verify the Rust Host detects the revision divergence, never overwrites user edits or applies to shifted offsets, and presents the conflict in `@codemirror/merge`.
- **`🟢 → 🟠 → 🟢/🔴` Local Edit Cycle Test (Blocking — Section 5 Blocking Scenario):** Editing a `🟢` range immediately marks it `🟠` and triggers debounced background re-verification.

### 4.6 Acceptance Criteria
- [ ] First `🟢/🔴` verdict on impacted tests delivered in **< 2 seconds**.
- [ ] Strict cap of **2 automatic retries** on `🔴 Failed`.
- [ ] Zero patches applied to wrong offsets and zero user edits overwritten.
- [ ] Interactive review via `@codemirror/merge`.

### 4.7 Definition of Done
AST `ChangeSet` compiler, Judge pipeline, Coloride states, and `@codemirror/merge` delivered and validated. Closes milestone `M1.3`.

### 4.8 Risks & Rollback
- **Risk:** Excessive background re-runs while the user is actively typing in an `🟠` block.
- **Mitigation:** Debounce background sandbox re-verification (`1.5 s` idle or explicit save).
