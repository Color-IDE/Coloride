# LOT-006 — 1-Click Onboarding, Migration & Declarative OpenVSX (`.vsix`) Loader

> 🇫🇷 [Version française](../fr/LOTS/LOT-006.md)

**Domain:** Core Editor Engine & Onboarding
**Module:** `crates/host-core` (`Migration & Onboarding Service`), `apps/web-ui`
**Milestone:** `M1.1 - Core & Cockpit Shell`
**Priority:** P1 | **Complexity:** Low | **Estimate:** 2.5 days (20 h)
**Dependencies:** [LOT-003](./LOT-003.md), [LOT-005](./LOT-005.md)

---

### 4.1 Objective
Provide a 1-click onboarding wizard on first launch that imports user settings from **VS Code**, **Cursor**, and **Claude Desktop** (keymaps with VS Code / Vim / JetBrains presets, color themes, project rules `.cursorrules` / `CLAUDE.md` / `AGENTS.md`, and quarantined MCP servers), plus a **Tier-1 native `.vsix` (OpenVSX) loader** for declarative extensions (themes, icons, snippets, keymaps, grammars).

### 4.2 Scope
- **IN:** Cross-OS configuration discovery (macOS, Windows, Linux), tolerant `JSONC` parser, keymap translator + `VS Code` / `Vim` / `JetBrains` presets, `.cursorrules` / `CLAUDE.md` / `AGENTS.md` project convention loader, MCP server import in locked `PendingApproval` quarantine state, and native Rust `.vsix` declarative asset loader.
- **OUT:** Imperative JS/TS `vscode.*` API runtime emulation (delivered in [LOT-029](./LOT-029.md) via the isolated `VS Code Extension Host Shim`).

### 4.3 Prerequisites
- [LOT-003](./LOT-003.md) and [LOT-005](./LOT-005.md).

### 4.4 Implementation
1. Implement read-only discovery of VS Code, Cursor, and Claude Desktop config paths across macOS, Windows, and Linux.
2. Redact sensitive environment variables in imported MCP configs and store them with `enabled = false, approval_required = true`.
3. Tag imported `.cursorrules`, `CLAUDE.md`, and `AGENTS.md` as `UntrustedProjectConvention` so they can never alter `Policy Engine` security rules.
4. Implement the native `.vsix` (ZIP) extractor loading declarative themes, icons, snippets, and keybindings into CodeMirror 6 and the Cockpit UI.

### 4.5 Mandatory Tests
- **Cross-OS JSONC & `.vsix` Parsing Unit Tests (Blocking):** Parse real `settings.json`, `keybindings.json` (with comments/trailing commas), and declarative `.vsix` packages.
- **MCP Import & `.cursorrules` Injection Security Test (Blocking):** Importing a malicious `claude_desktop_config.json` or `.cursorrules` launches `0` processes and changes `0` security permissions.

### 4.6 Acceptance Criteria
- [ ] 1-click import completes in `< 2 s` across macOS, Windows, and Linux.
- [ ] Zero imported MCP servers execute prior to explicit user approval.
- [ ] Declarative `.vsix` themes and snippets load cleanly into CodeMirror 6.

### 4.7 Definition of Done
Rust migration service, declarative `.vsix` loader, and onboarding UI delivered and tested. Closes milestone `M1.1`.

### 4.8 Risks & Rollback
- **Risk:** Malformed user configuration files.
- **Mitigation:** Per-file graceful degradation with detailed import report and 1-click reset to Coloride defaults.
