# LOT-027 — Enterprise Governance: SSO (OIDC/SAML/SCIM), RBAC/ABAC & Private vLLM

**Domain:** Scale & Enterprise (Phase 4 — Enterprise)
**Module:** Cloud Service, `crates/judge-orchestrator`, `apps/web-ui` (Admin)
**Milestone:** `M4.0 - Scale & Enterprise`
**Priority:** P2 | **Complexity:** Medium | **Estimate:** 5 days (40 h)
**Dependencies:** [LOT-014](./LOT-014.md), [LOT-017](./LOT-017.md), [LOT-022](./LOT-022.md)

---

### 4.1 Objective
Deliver the Enterprise governance foundation: **SSO (OIDC / SAML 2.0)** identity federation and automated **SCIM 2.0** provisioning, non-bypassable central **RBAC/ABAC** organization policies with an immutable audit log, and integration of homologated private **vLLM** model endpoints.

### 4.2 Scope
- **IN:** SAML 2.0 and OIDC Enterprise authentication + SCIM 2.0 server (user/group sync and immediate session/task revocation upon user deprovisioning); central **RBAC/ABAC** policy engine distributing cryptographically signed organization policies (allowed models, budget caps, approved MCP connectors, export rules by repository classification) to desktop clients; immutable central audit log; and `HomologatedVllmProvider` with an automated capability qualification suite (`VllmCapabilitySuite`).
- **OUT:** VPC/On-Premise deployment and RPO/RTO drills ([LOT-028](./LOT-028.md)).

### 4.3 Prerequisites
- [LOT-014](./LOT-014.md), [LOT-017](./LOT-017.md), [LOT-022](./LOT-022.md).

### 4.4 Implementation
1. Implement SAML 2.0 / SCIM 2.0 endpoints in the Axum Cloud service so `PATCH /Users/<id>` (`active: false`) revokes active JWTs, task leases, and SSE/WebSocket streams in `< 2 s`.
2. Implement `OrgPolicyEnforcer` in `crates/judge-orchestrator` verifying signed organization policies and blocking unapproved BYOK or public providers on confidential repositories.
3. Implement `HomologatedVllmProvider` and `VllmCapabilitySuite` validating structured tool calling, streaming, and context limits before enabling a private model in the organization catalog.

### 4.5 Mandatory Tests
- **Real-Time SCIM Deprovisioning & Central ABAC Policy Enforcement Test (Blocking):** Deprovision an active user via SCIM and verify task termination within `< 2 s`; attempt a BYOK call on a `Confidential`-classified repo and verify 100% client and server rejection with audit logging.
- **Private vLLM Homologation Suite Test (Blocking):** Verify `VllmCapabilitySuite` approves a compliant vLLM endpoint and rejects a misconfigured endpoint lacking structured tool-call support.

### 4.6 Acceptance Criteria
- [ ] SAML 2.0 / OIDC authentication and SCIM 2.0 provisioning (with immediate revocation) operational.
- [ ] Signed central RBAC/ABAC policies enforced end-to-end without local client bypass.
- [ ] Private vLLM routing validated by automated capability checks.

### 4.7 Definition of Done
SAML/SCIM, RBAC/ABAC, immutable audit log, and private vLLM connector delivered and validated.

### 4.8 Risks & Rollback
- **Risk:** Temporary network loss between a traveling laptop and the central policy server.
- **Mitigation:** Signed policy lease token with configurable TTL allowing offline local work under the last valid signed policy until lease expiration.
