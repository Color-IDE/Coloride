# LOT-023 — Real-Time Co-Editing (`y-codemirror.next` / Yjs) & Per-Origin Isolated Undo

> 🇫🇷 [Version française](../fr/LOTS/LOT-023.md)

**Domain:** Collaborative Editing (Phase 3 — Multi-Persona V1)
**Module:** `packages/editor-cm6`, `crates/host-core` (`yrs`), Cloud Service
**Milestone:** `M3.0 - V1 Multi-Personas`
**Priority:** P1 | **Complexity:** High | **Estimate:** 4.5 days (36 h)
**Dependencies:** [LOT-019](./LOT-019.md), [LOT-020](./LOT-020.md)

---

### 4.1 Objective
Implement real-time collaborative editing in V1 powered by **`y-codemirror.next` (Yjs)** and **`yrs` (Rust Host)**, explicitly opt-in per workspace, featuring a strictly **per-origin isolated `UndoManager`** separating the local user's undo/redo history from AI agent edits and remote human peers.

### 4.2 Scope
- **IN:** `y-codemirror.next` + `yrs` CRDT synchronization across peers and `host-core`; `Y.UndoManager` scoped to `trackedOrigins = { LocalHuman(current_user_id) }` so `Cmd+Z` / `Ctrl+Z` only undoes the local user's own typing and never reverts remote peer edits or agent patches; offline editing and reconnection convergence; and relative-position tracking for Coloride state decorations (`🟢/🟡/🔴/🟠/🔵`).
- **OUT:** Forced network CRDT sync on purely local unshared workspaces.

### 4.3 Prerequisites
- [LOT-019](./LOT-019.md) and [LOT-020](./LOT-020.md).

### 4.4 Implementation
1. Implement `YrsRopeBridge` in `crates/host-core` keeping `yrs::Doc` and `ropey::Rope` synchronized for `Tree-sitter`, `vtsls`, and the Judge.
2. Configure `UndoManager` with distinct origins: `Origin::LocalHuman(user_id)`, `Origin::RemotePeer(peer_id)`, and `Origin::Agent(task_id)`.

### 4.5 Mandatory Tests
- **CRDT Convergence, Reconnection & Per-Origin Isolated Undo Test (Blocking — Section 5 Blocking Scenario):** User `U1` edits line 2, agent `A1` inserts lines 20–30, peer `U2` goes offline, edits lines 5 and 40, and reconnects; `U1` then triggers `Undo` (`Cmd+Z`). Verify 100% document convergence across `U1`, `U2`, and the Rust Host, and verify `U1`'s Undo reverts only line 2 while preserving `U2`'s and `A1`'s changes.

### 4.6 Acceptance Criteria
- [ ] 100% document convergence across peers and Rust Host after concurrent edits and network disconnections.
- [ ] 100% per-origin Undo isolation (zero remote or agent changes accidentally undone by local Undo).

### 4.7 Definition of Done
`y-codemirror.next` / `yrs` co-editing and per-origin `UndoManager` delivered and qualified on the Section 5 blocking scenario.

### 4.8 Risks & Rollback
- **Risk:** Unbounded Yjs state vector growth on long-lived sessions.
- **Mitigation:** Compact CRDT snapshots upon validated Git commits.
