### 4.1 Objective
Produce code-signed installers and automatic update mechanisms across all three target OSes (**macOS Apple Silicon**, **Windows 11 x64**, **Ubuntu 24.04 x64**), validate native accessibility (VoiceOver, NVDA, Orca), and execute all blocking MVP qualification scenarios alongside the 100-task TypeScript benchmark.

### 4.2 Scope
- **IN:** Signed & notarized `.dmg`/`.app` (macOS Apple Silicon), Authenticode-signed `.msi`/`.exe` (Windows 11 x64), and signed `.deb`/`.AppImage` (Ubuntu 24.04 x64); signed `Tauri Updater` with compatible transactional SQLite schema migration and automatic rollback; native keyboard, zoom, and screen reader validation (**VoiceOver**, **NVDA**, **Orca**); automated evaluation harness on **100 held-out representative TypeScript tasks** (**≥ 70%** pass target); and execution of all applicable Section 5 blocking scenarios.
- **OUT:** V1-exclusive scenarios (Yjs co-editing [LOT-023](./LOT-023.md) and DBA SQL migrations [LOT-024](./LOT-024.md)).

### 4.3 Prerequisites
- [LOT-001](./LOT-001.md) through [LOT-017](./LOT-017.md) completed.

### 4.4 Implementation
1. Configure multi-OS code signing and `DatabaseSchemaMigrator` with pre-migration backup and `N-1` recovery.
2. Certify ARIA announcements (`aria-live="polite"` on `🟢/🟡/🔴/🟠/🔵` state transitions) and full keyboard-only diff review across WebKit (macOS/Linux) and WebView2 (Windows).
3. Run the full blocking scenario matrix on native macOS, Windows, and Ubuntu runners plus the 100-task TypeScript benchmark.

### 4.5 Mandatory Tests
- **Signed Desktop Update & Data Migration Test (Blocking — Section 5 Blocking Scenario):** Upgrade signed `0.1.0` → `0.1.1` across all 3 OSes preserving journaled buffers, checkpoints, and SQLite indices; verify rejection of an invalidly signed update package.
- **Keyboard, Zoom & Screen Reader Accessibility Validation (Blocking — Section 5 Blocking Scenario):** Complete editing and diff review using VoiceOver, NVDA, and Orca at 100% and 200% zoom.
- **100-Task TypeScript MVP Benchmark Campaign (Blocking):** Achieve **≥ 70%** Judge-verified (`🟢 ✓ Validated`) resolution within budget.

### 4.6 Acceptance Criteria
- [ ] 100% of applicable Section 5 blocking scenarios pass via real execution across macOS, Windows, and Ubuntu.
- [ ] All MVP p95 latency targets met on documented reference hardware.
- [ ] **≥ 70%** pass rate on the 100 held-out TypeScript tasks.

### 4.7 Definition of Done
Signed 3-OS installers published, security and qualification report signed. **Milestone `M1 - Release MVP Alpha` achieved.**

### 4.8 Risks & Rollback
- **Risk:** OS-specific WebView rendering regression.
- **Rollback:** Signed updater rollback to `N-1` release.
