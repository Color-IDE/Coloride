# LOT-007 — Incremental `Tree-sitter` AST Analysis & Symbol Graph

> 🇫🇷 [Version française](../fr/LOTS/LOT-007.md)

**Domain:** Context Engine
**Module:** `crates/context-engine`
**Milestone:** `M1.2 - Context & Fast Quality`
**Priority:** P0 | **Complexity:** Medium | **Estimate:** 3.5 days (28 h)
**Dependencies:** [LOT-003](./LOT-003.md)

---

### 4.1 Objective
Integrate `Tree-sitter` into `crates/context-engine` to incrementally parse in-memory `ropey` buffers, extract syntactic blocks and symbols (TS/TSX/JS/JSON/CSS), build the dependency graph with explicit confidence levels, and compute impacted tests (*Test Impact Analysis*).

### 4.2 Scope
- **IN:** Incremental `tree-sitter` parser reading directly from `ropey::Rope` chunks via `Tree::edit`, symbol extractor (functions, React components, classes, interfaces, types, imports/exports) with byte/line ranges and `blake3` node hashes, dependency graph annotated with `ConfidenceLevel` (`ExactSemantic`, `SyntacticAst`, `HeuristicText`), and *Test Impact Analysis* resolving `*.test.ts(x)` / `*.spec.ts(x)` files covering modified symbols.
- **OUT:** SQLite FTS5 persistence ([LOT-008](./LOT-008.md)), `vtsls` LSP semantic enrichment ([LOT-010](./LOT-010.md)).

### 4.3 Prerequisites
- [LOT-003](./LOT-003.md).

### 4.4 Implementation
1. Implement `RopeTextProvider` for `tree_sitter::Parser::parse_with` to avoid contiguous buffer copies.
2. Translate `EditorTransaction` deltas into `tree_sitter::InputEdit` and update the syntax tree in `< 5 ms`.
3. Extract symbol definitions and import edges annotated with confidence levels.
4. Implement `ImpactAnalyzer::find_impacted_tests(modified_symbols)` traversing reverse dependency edges to affected test files.

### 4.5 Mandatory Tests
- **Incremental Parsing Equivalence Property Test (`proptest`, Blocking):** 200 random edits on a 1,500-line TypeScript file yield an S-expression tree 100% identical to a cold full parse, in **p95 < 5 ms**.
- **Syntax Error Resilience & Test Impact Analysis Unit Test (Blocking):** Modify a symbol with a temporary syntax error on the next line; verify `Tree-sitter` preserves surrounding symbols and `find_impacted_tests` returns the covering test files in `< 10 ms`.

### 4.6 Acceptance Criteria
- [ ] Incremental `Tree-sitter` re-parse on `ropey::Rope` in **p95 < 5 ms**.
- [ ] Every graph edge carries an explicit confidence level.
- [ ] Accurate identification of impacted test files for the Judge's `< 2 s` fast feedback loop ([LOT-015](./LOT-015.md)).

### 4.7 Definition of Done
AST parser, dependency graph, and *Test Impact Analysis* delivered and verified in `crates/context-engine`.

### 4.8 Risks & Rollback
- **Risk:** Incorrect `Point { row, column }` calculation on multi-line deletions.
- **Mitigation:** Use `ropey::Rope` line metrics validated in [LOT-003](./LOT-003.md).
