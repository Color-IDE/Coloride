# LOT-004 — Isolated CodeMirror 6 Editor & Binary IPC Bridge (`editor-cm6`)

> 🇫🇷 [Version française](../fr/LOTS/LOT-004.md)

**Domain:** CM6 Editor View & IPC
**Module:** `packages/editor-cm6`, `apps/desktop-tauri`
**Milestone:** `M1.1 - Core & Cockpit Shell`
**Priority:** P0 | **Complexity:** High | **Estimate:** 4 days (32 h)
**Dependencies:** [LOT-002](./LOT-002.md), [LOT-003](./LOT-003.md)

---

### 4.1 Objective
Build the **CodeMirror 6** editor package strictly isolated from React's re-render cycle, featuring instant local syntax highlighting (< 2 ms via Lezer), binary delta synchronization with `crates/host-core` via `tauri::ipc::Channel`, full IME composition coordination, and the 5 Coloride validation state decorations with immediate local invalidation (`🟢 → 🟠`).

### 4.2 Scope
- **IN:** Imperatively mounted `EditorView` (`@codemirror/state`, `@codemirror/view`), Lezer grammars (TS/TSX/JS/JSON/CSS/HTML/Markdown < 2 ms), binary IPC delta bridge, IME composition lock (`compositionstart` / `compositionend`), `(document_id, session_generation)` guard on rapid tab switching, and `StateField`/`Decoration` for the 5 Coloride states (`🟢/🟡/🔴/🟠/🔵`) with synchronous `< 1 ms` transition from `🟢` to `🟠` on local edit.
- **OUT:** `@codemirror/merge` Judge review ([LOT-015](./LOT-015.md)), `vtsls`/Biome diagnostics ([LOT-010](./LOT-010.md)), advanced multi-cursor/folding ([LOT-019](./LOT-019.md)).

### 4.3 Prerequisites
- [LOT-002](./LOT-002.md) and [LOT-003](./LOT-003.md).

### 4.4 Implementation
1. Mount `EditorView` inside a memoized container immune to parent React state changes.
2. Implement `hostDeltaSyncPlugin` emitting binary `EditorTransaction` payloads and deferring snapshot freezes until IME `compositionend`.
3. Drop any delayed incoming IPC event whose `(document_id, session_generation)` does not match the active buffer.
4. Implement `colorideStateDecorations`: render color + distinct icon (`✓`, `!`, `✕`, `⟳`, `•`) + accessible label, and synchronously downgrade any touched `🟢 Validated` range to `🟠 Stale Validation`.

### 4.5 Mandatory Tests
- **Unicode, IME & Rapid File Switch Integration Test (Blocking — Section 5 Blocking Scenarios):** Verify IME composition safety and switch across 10 files in < 100 ms with artificially delayed IPC events; verify zero content cross-contamination.
- **Immediate Local Invalidation `🟢 → 🟠` Test (Blocking):** Editing 1 character inside a `🟢` range switches its state to `🟠` in the same synchronous transaction (< 1 ms).
- **Typing & File Open Performance Tests (Blocking):** Keystroke-to-display **p95 ≤ 16 ms**; Lezer highlighting **< 2 ms**; 1 MB file open **p95 ≤ 150 ms**.

### 4.6 Acceptance Criteria
- [ ] `p95 ≤ 16 ms` keystroke responsiveness in CodeMirror 6.
- [ ] `p95 ≤ 150 ms` to open and render a local file `≤ 1 MB`.
- [ ] Immediate local invalidation `🟢 → 🟠` on character edit.

### 4.7 Definition of Done
`@coloride/editor-cm6` integrated with `desktop-tauri` and `host-core`, all IPC, IME, and latency tests passing.

### 4.8 Risks & Rollback
- **Risk:** IPC bottleneck on multi-megabyte clipboard paste.
- **Mitigation:** Stream raw binary payloads over `tauri::ipc::Channel` without JSON serialization overhead.
