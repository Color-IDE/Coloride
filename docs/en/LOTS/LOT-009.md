# LOT-009 — Local MCP Server (< 20 ms) & Optional Embeddings (`sqlite-vec`)

> 🇫🇷 [Version française](../fr/LOTS/LOT-009.md)

**Domain:** Context Engine & MCP Connectors
**Module:** `crates/context-engine`
**Milestone:** `M1.2 - Context & Fast Quality`
**Priority:** P1 | **Complexity:** Medium | **Estimate:** 3 days (24 h)
**Dependencies:** [LOT-008](./LOT-008.md)

---

### 4.1 Objective
Expose the `Context Engine` as an **ultra-fast local MCP server (< 20 ms)** for internal and external agents (Claude Code, Codex), implement the token-budgeted `ContextBundle` assembler (16,000 tokens default), and integrate optional background vector indexing via `sqlite-vec` (< 150 MB) with explicit degradation.

### 4.2 Scope
- **IN:** Local MCP server (`stdio` / local IPC) exposing `search_codebase`, `get_symbol_definition`, `get_impact_graph`, `get_diagnostics`, and `build_context_bundle`; `ContextBundle` assembler enforcing token budgets (16,000 tokens default), deduplication, and export destination policy; optional `sqlite-vec` extension with compact embedding model (< 150 MB, e.g. `nomic-embed-code` / `bge-small`) downloaded on demand; explicit fallback to FTS5 + AST/LSP graph when vector index is disabled or unavailable.
- **OUT:** External ACP agent supervision ([LOT-014](./LOT-014.md)).

### 4.3 Prerequisites
- [LOT-008](./LOT-008.md).

### 4.4 Implementation
1. Implement `ContextBundleAssembler` combining BM25, AST/LSP graph proximity, and optional `sqlite-vec` cosine similarity, ordering stable files into a deterministic prefix for *Prompt Caching*.
2. Enforce export policy checks (`authorized_destination`) before returning any `ContextBundle`.
3. Expose the JSON-RPC 2.0 local MCP server backed directly by memory-mapped SQLite `WAL`/`mmap`.

### 4.5 Mandatory Tests
- **Local MCP Server Latency Test (Blocking):** 200 local MCP tool calls complete in **p95 < 20 ms**.
- **Explicit Degradation & Token Budget Test (Blocking):** With vector embeddings disabled and a `8,000 token` budget, `build_context_bundle` succeeds with `≤ 8,000 tokens` and explicitly reports `LexicalAndAstOnly` mode.

### 4.6 Acceptance Criteria
- [ ] Local MCP server response time measured at **p95 < 20 ms**.
- [ ] 100% enforcement of the `ContextBundle` token budget and provenance metadata.
- [ ] Automatic vector invalidation upon embedding model change or Git branch switch.

### 4.7 Definition of Done
Local MCP server, `ContextBundle` assembler, and optional `sqlite-vec` module delivered and verified in `crates/context-engine`.

### 4.8 Risks & Rollback
- **Risk:** Prompt injection embedded inside indexed source files returned via MCP.
- **Mitigation:** Wrap all `ContextBundle` excerpts in typed untrusted-data delimiters with exact provenance (`file_path`, `snapshot_hash`).
