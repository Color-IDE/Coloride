# LOT-016 — Isolated `Preview Service` (Browser Loop) & Runtime `Evidence` Capture

> 🇫🇷 [Version française](../fr/LOTS/LOT-016.md)

**Domain:** Core Editor Engine & Frontend Validation
**Module:** `crates/host-core` (`Preview Service`), `apps/web-ui`, `crates/judge-orchestrator`
**Milestone:** `M1.4 - MVP Launch Ready`
**Priority:** P0 | **Complexity:** Medium | **Estimate:** 3 days (24 h)
**Dependencies:** [LOT-015](./LOT-015.md)

---

### 4.1 Objective
Integrate the **`Preview Service (Browser Loop)`** on a strictly isolated origin with zero access to the Tauri IPC bridge, automatically capturing runtime errors (`console.error`, unhandled exceptions, network failures) and the DOM/accessibility tree to feed the Judge's `Evidence` before granting `🟢 ✓ Validated`.

### 4.2 Scope
- **IN:** Isolated preview server on a distinct origin (ephemeral local port or isolated custom scheme with `window.__TAURI__ === undefined`) and sandboxed iframe; lightweight runtime instrumentation probe capturing `window.onerror`, `unhandledrejection`, `console.error`, failed HTTP requests, and DOM/a11y tree snapshots; and integration into `Evidence` ([LOT-015](./LOT-015.md)) so any UI component that compiles statically but crashes at render time is marked `🔴 ✕ Failed` and returned to the agent.
- **OUT:** Visual No-Code catalog element selection ([LOT-021](./LOT-021.md)).

### 4.3 Prerequisites
- [LOT-015](./LOT-015.md).

### 4.4 Implementation
1. Serve the worktree preview from a distinct origin with strict `Content-Security-Policy` and `Cross-Origin-Opener-Policy` headers and assert `window.__TAURI__ === undefined`.
2. Collect `PreviewRuntimeReport { uncaught_exceptions, console_errors, failed_requests, a11y_tree_summary }` via schema-validated messages and attach it to `Evidence`.

### 4.5 Mandatory Tests
- **Malicious Generated Preview Security Test (Blocking — Section 5 Blocking Scenario):** Render a malicious component attempting to access `window.__TAURI__`, `window.top.document`, or IDE credentials; verify 100% isolation and refusal.
- **React Runtime Crash Rejection by Judge (Blocking):** A `.tsx` component with 0 TypeScript/Biome errors that throws a runtime `ReferenceError` or `console.error` on mount is rejected by the Judge (`🔴 ✕ Failed`) with its runtime stacktrace attached to `Evidence`.

### 4.6 Acceptance Criteria
- [ ] 100% origin isolation between `Preview Service` and the Tauri control plane.
- [ ] Zero `🟢 ✓ Validated` status granted to frontend tasks if `Preview Service` detects an unhandled exception or `console.error`.

### 4.7 Definition of Done
Isolated `Preview Service` and `Evidence` runtime collector delivered and validated across all 3 OSes.

### 4.8 Risks & Rollback
- **Risk:** Infinite synchronous `while(true)` loop inside user preview code.
- **Mitigation:** 3-second render watchdog terminating and reloading the isolated preview frame without freezing the IDE.
