**Dependencies:** [LOT-009](./LOT-009.md), [LOT-013](./LOT-013.md)

---

### 4.1 Objective
Implement the unified `Model Gateway` supporting account-free local inference (`llama.cpp` / Ollama for Qwen2.5-Coder 1.5B/7B), BYOK mode (keys in OS keyring), and Managed Cloud mode (`claude-sonnet-5-5`, `gpt-6-astra`), alongside the **ACP (Agent Client Protocol) / SDK** bridge supervising Claude Code, OpenAI Codex, or Copilot SDK under the Rust Judge.

### 4.2 Scope
- **IN:** Versioned model registry; unified local inference runtime (`llama.cpp` / Ollama) with fast short completion (**p95 ≤ 700 ms** on 1.5B) and immediate cancellation on new keystroke; OS keyring BYOK secret store (macOS Keychain, Windows Credential Manager, Linux Secret Service) kept strictly out of build sandboxes; strict privacy routing (zero silent fallback to remote providers on local/network failure); and **ACP / SDK supervisor** connecting Claude Code, Codex, and Copilot SDK to Coloride's `< 20 ms` local MCP server ([LOT-009](./LOT-009.md)) while intercepting all proposed edits and tool calls.
- **OUT:** Enterprise private vLLM endpoints ([LOT-027](./LOT-027.md)).

### 4.3 Prerequisites
- [LOT-009](./LOT-009.md) and [LOT-013](./LOT-013.md).

### 4.4 Implementation
1. Implement `ModelRegistry` and `ModelGateway` enforcing workspace privacy policy and budget reservation before every call.
2. Implement `OsKeyringSecretStore` for BYOK credentials, ensuring `0` LLM secrets ever enter sandbox environment variables.
3. Wire local 1.5B completion cancellation to `host-core` keystroke events (`< 1 ms` `CancellationToken::cancel()`).
4. Implement `AcpSessionSupervisor` routing external agent proposals into `ChangeSet` and `ToolCall` structs verified by the Judge ([LOT-015](./LOT-015.md)).

### 4.5 Mandatory Tests
- **Network Outage / Provider Failure Without Implicit Privacy Fallback (Blocking — Section 5 Blocking Scenario):** Simulate a failure of the configured local or BYOK provider while another cloud provider exists; verify `0` network packets are sent to the unapproved destination and state is preserved.
- **Local Completion Latency & Cancellation Test (Blocking):** Qwen2.5-Coder 1.5B completion **p95 ≤ 700 ms**; immediate cancellation on new keystroke.
- **LLM Secret Isolation Test (Blocking):** Verify `0` BYOK keys are visible inside sandbox environment variables.

### 4.6 Acceptance Criteria
- [ ] Strict local mode operational with zero user account required.
- [ ] Short local AI completion measured at **p95 ≤ 700 ms**.
- [ ] Zero silent remote fallback on network or provider outage.
- [ ] External ACP/SDK agents connected to the local MCP server and intercepted by the Rust Host.

### 4.7 Definition of Done
`Model Gateway`, OS keyring BYOK store, unified local runtime, and ACP/SDK bridge delivered and verified.

### 4.8 Risks & Rollback
- **Risk:** Memory pressure when loading the 7B model on low-RAM machines.
- **Mitigation:** Pre-flight RAM/VRAM check recommending 1.5B or BYOK/Cloud when free memory is insufficient.
