### 4.1 Objective
Establish the target monorepo structure (`Cargo Workspace` + `pnpm workspaces`) with all 4 Rust crates and 4 TypeScript packages/apps, compilable and tested across macOS (Apple Silicon), Windows 11 x64, and Ubuntu 24.04 x64 via GitHub Actions.

### 4.2 Scope
- **IN:** Root `Cargo.toml` (`host-core`, `context-engine`, `judge-orchestrator`, `sandbox-runner`, `apps/desktop-tauri/src-tauri`), `pnpm-workspace.yaml` (`apps/desktop-tauri`, `apps/web-ui`, `packages/editor-cm6`, `packages/protocol-types`), unified **Biome** (`biome.json`), strict TypeScript configuration, minimal Tauri v2 shell with strict CSP, and 3-OS workflow [`.github/workflows/ci.yml`](../../../.github/workflows/ci.yml).
- **OUT:** Editing business logic, binary IPC streams, SQLite indexing, agents, and sandboxes.

### 4.3 Prerequisites
- Stable Rust toolchain, Node.js LTS (`>= 22`) + `pnpm` (`>= 10`), Tauri v2 system dependencies.

### 4.4 Implementation
1. Create root `Cargo.toml` with workspace members, shared dependencies (`tokio`, `serde`, `serde_json`, `thiserror`, `tracing`, `blake3`), and `unsafe_code = "forbid"`.
2. Create `pnpm-workspace.yaml`, root `package.json`, `biome.json`, `tsconfig.base.json`, and root solution `tsconfig.json`.
3. Initialize the 4 Rust crates (`host-core`, `context-engine`, `judge-orchestrator`, `sandbox-runner`) and `apps/desktop-tauri/src-tauri` with healthcheck functions and unit tests.
4. Initialize `packages/protocol-types`, `packages/editor-cm6`, `apps/web-ui`, and `apps/desktop-tauri` with strict TypeScript and Vitest unit tests.
5. Configure [`.github/workflows/ci.yml`](../../../.github/workflows/ci.yml) for Ubuntu, macOS, and Windows.

### 4.5 Mandatory Tests
- **Workspace Unit Tests (Blocking):** `cargo test --workspace` and `pnpm test` pass with exit code `0`.
- **Multi-OS CI Integration Test (Blocking):** `pnpm lint`, `pnpm typecheck`, `cargo fmt --all -- --check`, and `cargo clippy --workspace --all-targets -- -D warnings` pass with `0` errors and `0` warnings.

### 4.6 Acceptance Criteria
- [x] Monorepo tree matches the target architecture in [ARCHITECTURE_TECHNIQUE.md](../ARCHITECTURE_TECHNIQUE.md).
- [x] `cargo clippy --workspace --all-targets -- -D warnings` and `pnpm typecheck` return `0` errors.
- [x] All Rust and TypeScript unit tests pass.

### 4.7 Definition of Done
Implemented, formatted with Biome / `rustfmt`, all acceptance criteria and tests green.

### 4.8 Risks & Rollback
- **Risk:** WebKitGTK package name variations on Ubuntu 24.04 (`libwebkit2gtk-4.1-dev`).
- **Rollback:** Atomic revert of initialization commit if CI matrix fails.
